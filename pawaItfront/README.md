# Travel Documentation Assistant

Travel Documentation Assistant is an AI-powered platform designed to provide accurate and up-to-date travel documentation and visa requirements for any destination. Whether you're planning a trip or need real-time updates on travel advisories, this tool has you covered.

## Features

- **AI-Powered Insights**: Advanced Claude AI provides accurate and up-to-date travel documentation requirements.
- **Real-Time Updates**: Get the latest visa requirements, travel advisories, and documentation changes.
- **Reliable Information**: Comprehensive travel guidance with official source recommendations.
- **User-Friendly Interface**: Intuitive design for seamless navigation and interaction.
- **Personalized Query History**: Save and revisit your previous queries for convenience.
- **Secure Authentication**: Users can create accounts and log in securely to access personalized features.

## Authentication

The application supports user authentication for a personalized experience:

- **Create an Account**: Users can register by providing their name, email, and password.
- **Login**: Existing users can log in using their email and password.
- **Session Management**: User sessions are securely managed using tokens stored in the browser's local storage.
- **Logout**: Users can log out at any time, clearing their session data.

## Setup

Make sure to install dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev -- -o

# pnpm
pnpm dev

# yarn
yarn dev

# bun
bun run dev
```

## Production

Build the application for production:

```bash

# yarn
```
