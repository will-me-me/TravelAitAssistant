# Travel AI Assistant

This repository contains both the backend and frontend code for the Travel AI Assistant project.

## Getting Started

To run the code, follow the steps below:

### Backend

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the backend directory:
   ```bash
   cd pawaItbackend
   ```
3. Refer to the `README.md` file in the `pawaItbackend` directory for instructions on how to run the backend server.

### Frontend

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the frontend directory:
   ```bash
   cd pawaItfront
   ```
3. Refer to the `README.md` file in the `pawaItfront` directory for instructions on how to run the frontend server.
